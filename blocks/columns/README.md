# columns

Custom **columns** block. 

## Authoring (Document Authoring)

Model: `columns`

Block table with one cell per column in each row.
With the `consent` option, the text column ends with a short paragraph (e.g. "I understand") followed by a link: the paragraph becomes a checkbox label and the link becomes a button that stays disabled until the box is ticked.

## Supported variations

| Variation | Option class |
| --- | --- |
| Consent (checkbox-gated CTA) | `consent` |
