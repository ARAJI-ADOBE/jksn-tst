# hero

Custom **hero** block. 

## Authoring (Document Authoring)

Model: `hero`

Block table with an image row and a text row (heading, paragraphs, lists, links).
With the `split` option the image is shown to the right of the text; without it, the image sits behind the text.

## Supported variations

| Variation | Option class |
| --- | --- |
| Split (image beside text) | `split` |
